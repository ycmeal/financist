# Пиксельные картинки шапки «Трат»

Отсюда берутся рисунки для `Financist/Models/PixelData.swift` и для кликабельного макета.
Нужен только Node.js, без пакетов.

- `scenes/*.js` — места. Турция: Стамбул, Каппадокия, Галата, Памуккале, Олюдениз, Эфес, Узунгёль.
  Узбекистан: Самарканд, Хива, Бухара, Гур-Эмир, Ташкент, Чимган, базар Чорсу. ОАЭ: Дубай, пустыня.
  Россия: Москва, деревня. Европа: Париж, побережье. США: Нью-Йорк. Городок — когда страна неизвестна.
- `pieces.js`, `lib.js` — общие детали: минареты, купола, пальмы, деревья, горы, барханы, шары.
- `flags.js` — флаги 15×10, нарисованные вручную, — только стран, чьи валюты есть в приложении, и Европы.
- `materials.js` — цвета материалов днём и что горит вечером.
- `build.js` — какие места у какой страны; с каждым входом в приложение показывается следующее.
- `runtime.js` — как рисовать кадр. Тот же алгоритм, что в `PixelCity.swift`: менять оба.

Как поменять картинку:

1. Поправить сцену и выполнить `node build.js` — соберутся `data.js` и `data.json`.
2. Открыть `grid.html` в браузере: все места на рассвете, днём, на закате и ночью.
   `grid.html?scenes=istanbul,moscow&guides` — только эти места и рамки, где лежит текст и кнопки.
3. `node gen-swift.js` — перезапишет `Financist/Models/PixelData.swift`.
4. `node ref.js` — новые контрольные суммы; вписать их в `PixelCityTests.testSamePicturesAsTheMockup`.
