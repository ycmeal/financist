# Financist

Простой и тёплый учёт трат для iPhone. Базовая валюта — доллар, удобно жить в разных странах. Всё хранится только на телефоне.

SwiftUI, iOS 17+, без сторонних зависимостей. Интерфейс на русском, поддерживается крупный шрифт (Dynamic Type).

## Что умеет
- **Ввод траты** — сумма, валюта, категория, комментарий, дата.
  - Валюта запоминается: подставляется та, что выбрана в прошлый раз, а последние валюты показаны кнопками.
  - Комментарии запоминаются: при вводе приложение подсказывает прошлые («Migros» → сразу категория «Продукты»).
  - Категории показаны плитками, частые — сверху (недавние траты весят больше). Своя категория создаётся прямо из формы (кнопка «Своя»).
  - Любую трату можно открыть и изменить. Там же видна сумма во всех валютах.
- **Валюты** — USD (база), TRY, EUR, RUB, UZS, AED. Курс к 1 USD обновляется сам, можно задать свой (курс обменника) или совсем выключить интернет. Каждая трата помнит курс на день записи.
- **Календарь** — на вкладке «Траты» переключатель «Список / Календарь»: дни подсвечены по сумме, нажатие на день показывает его траты, можно добавить трату задним числом.
- **Повтор трат** — блок «Повторить недавнюю» в форме, свайп вправо «Повторить», долгое нажатие на трату.
- **Бюджет на месяц** — полоска «осталось» и сколько можно тратить в день.
- **Регулярные платежи** — аренда, связь: в нужный день карточка «Пора оплатить», напоминание без сумм.
- **Сканер чека** — фото чека, сумма и магазин распознаются прямо на iPhone.
- **Напоминание вечером**, **Siri и кнопка действия** («Новая трата в Financist»), **«месяц закрыт»** — итог прошлого месяца в первые дни нового.
- **Итоги** — месяц или год:
  - сумма и сравнение с тем же отрезком прошлого периода;
  - «Главное»: средний расход в день, главная категория, самый затратный день, самая крупная трата, любимое место, дни без трат, любимый день недели;
  - кольцевая диаграмма по категориям, график по дням / месяцам, график по дням недели;
  - «Где тратили» (по валютам/странам), частые места;
  - «Все месяцы» — история итогов с переходом в любой месяц.
- **Виджет на экран блокировки** — кнопка «+», одно касание открывает ввод траты. На iOS 18 — ещё и кнопка вместо фонарика/камеры и в Пункте управления. Виджет не показывает суммы.
- **Перенос на новый iPhone** — файл, зашифрованный паролем; отправка через AirDrop или «Файлы»; пошаговая инструкция в приложении.
- **Конфиденциальность** — шифрование AES-256-GCM, ключ только на этом устройстве, без iCloud, без аналитики, сторонние клавиатуры отключены, Face ID. Подробно — в [PRIVACY.md](PRIVACY.md).

## Как запустить на iPhone
1. Нужен Mac с **Xcode 16** или новее.
2. Откройте `Financist.xcodeproj`.
3. Слева нажмите на проект **Financist** → вкладка **Signing & Capabilities**.
4. Для **обоих** таргетов (`Financist` и `FinancistWidgetExtension`) выберите свою команду (Team).
   Если Xcode ругается на bundle id, замените `com.ycmeal.financist` на свой, а у виджета — на `<ваш id>.widget`.
5. Подключите iPhone кабелем, выберите его сверху и нажмите **Run** (▶).
6. При первом запуске на iPhone: **Настройки → Основные → VPN и управление устройством** → доверьте своему профилю разработчика.

С бесплатным Apple ID приложение работает 7 дней, потом его нужно снова запустить из Xcode. С платной подпиской разработчика можно поставить через TestFlight.

## Как поставить виджет
Инструкция есть в приложении: **Настройки → Виджет на экран блокировки**.

## Как перенести данные на новый iPhone
Инструкция есть в приложении: **Настройки → Перенос на новый iPhone**. Коротко: на старом — «Сохранить файл», придумать пароль, отправить по AirDrop; на новом — открыть файл, ввести пароль.

## Структура
```
Financist/
  App/          точка входа, запрет сторонних клавиатур
  Models/       валюты, траты, категории, подсказки, статистика
  Storage/      AppStore (состояние) и EncryptedStore (шифрование, файл переноса)
  Services/     загрузка курсов
  Views/        Траты, форма траты, Итоги, Настройки, Курсы, Категории, Перенос, Виджет, Политика
FinancistWidget/  виджет экрана блокировки и кнопка Пункта управления
```

## Публикация в App Store
- Privacy Policy URL — ссылка на `PRIVACY.md` или его копию на сайте.
- App Privacy: **Data Not Collected**.
- В Info.plist стоит `ITSAppUsesNonExemptEncryption = NO`: используется только стандартное шифрование iOS/CryptoKit для данных пользователя. Перед отправкой в App Store проверьте, что такой ответ вам подходит.
