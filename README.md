# Financist

iOS-приложение для учёта трат в нескольких валютах. SwiftUI, iOS 17+, без сторонних зависимостей.

## Что умеет
- **Трата** — сумма, валюта, курс к 1 USDT (можно поправить вручную), заметка, категория, дата.
- **Валюты** — USDT (базовая), TRY, USD, EUR, RUB, UZS, AED.
- **Курсы** — сами обновляются из интернета (open.er-api.com + CoinGecko для USDT) не реже раза в 6 часов, плюс pull-to-refresh. На любую валюту можно задать свой курс (например, курс обменника). Каждая трата запоминает курс на момент записи, поэтому старые траты пересчитываются по тогдашнему курсу.
- **Просмотр в любой валюте** — переключатель валюты отображения в «Тратах» и «Анализе». На вкладке «Курсы» есть конвертер.
- **Подсказки при вводе** — приложение запоминает, какую категорию ты ставишь для места, и подставляет её («Migros» → Продукты). Для турецких сетей (Migros, File, Kasaba, A101, BİM, ŞOK, Getir, Yemeksepeti…) подсказки есть сразу.
- **Категории** — Продукты, Рестораны, Доставка, Развлечения, Связь, Жильё, Здоровье, Покупки, Транспорт, Другое. Можно добавлять, переименовывать, менять значок/цвет, сортировать.
- **Анализ** — неделя / месяц / год / всё время; кольцевая диаграмма по категориям, столбики по дням или месяцам, текстовое резюме: средний расход в день, главная категория, сравнение с тем же отрезком прошлого периода, что выросло, самая крупная трата, самое частое место.
- **Защита** — данные шифруются AES-256-GCM, ключ лежит в Связке ключей (только это устройство). Есть блокировка Face ID / код-паролем, а в переключателе приложений экран скрыт. Подробности — в [PRIVACY.md](PRIVACY.md).
- **Данные** — резервная копия, зашифрованная паролем, восстановление из неё, экспорт в CSV, полное удаление.

## Как запустить
1. Нужен Mac с **Xcode 16** или новее.
2. Открой `Financist.xcodeproj`.
3. Target **Financist → Signing & Capabilities**: выбери свою команду (Team). Если Xcode пожалуется на bundle id, поменяй `com.ycmeal.financist` на свой.
4. Подключи iPhone (или выбери симулятор) и нажми **Run**.

Проект использует папки, которые Xcode синхронизирует сам, поэтому новые `.swift` файлы в `Financist/` подхватываются без правки проекта.

## Структура
```
Financist/
  App/          точка входа
  Models/       валюты, траты, категории, подсказки, аналитика
  Storage/      AppStore (состояние) и EncryptedStore (шифрование, бэкапы)
  Services/     загрузка курсов
  Views/        экраны: Траты, Форма траты, Анализ, Курсы, Настройки, Категории, Политика
```

## Публикация в App Store
- В App Store Connect в поле Privacy Policy URL укажи ссылку на `PRIVACY.md` (или на его копию на сайте).
- App Privacy: **Data Not Collected**.
- Export compliance: приложение использует только стандартное шифрование iOS/CryptoKit для данных на устройстве. Обычно это подпадает под исключение, но ответ в анкете Apple должен дать ты сам.
