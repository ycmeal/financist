# Политика конфиденциальности Financist

_Редакция от 28 октября 2026 года_

## Коротко
Financist хранит траты **только на вашем iPhone**, в зашифрованном виде. Нет аккаунтов, серверов, рекламы, аналитики и сторонних SDK. Статистика и подсказки считаются на телефоне. Разработчик не получает никаких данных.

## Только на этом iPhone
Траты, категории, курсы и настройки лежат в одном файле в папке приложения. Файл не синхронизируется через iCloud и исключён из резервных копий iCloud и компьютера.

## Шифрование
- Перед записью на диск данные шифруются **AES-256-GCM** (Apple CryptoKit). GCM также не даёт незаметно подменить содержимое.
- Ключ (256 бит) создаётся случайно на iPhone и хранится в **Связке ключей iOS** с доступом `WhenUnlockedThisDeviceOnly`: «только на этом устройстве, только когда оно разблокировано». Ключ не попадает в iCloud Keychain и в резервные копии.
- Поверх этого файл записан с классом защиты iOS **Complete Protection**: пока телефон заблокирован, iOS держит файл зашифрованным ключом, производным от код-пароля.
- Ни у разработчика, ни у Apple ключа нет.

## Статистика
Итоги, графики, инсайты и подсказки комментариев считаются прямо на телефоне. Ничего не отправляется наружу.

## Курсы валют
Это единственное, для чего приложение выходит в интернет. Оно скачивает общие таблицы курсов:
- `open.er-api.com` — курсы валют к доллару;
- `api.coingecko.com` — цена USDT.

В этих запросах нет ваших трат, сумм, имени или идентификаторов устройства. Сервисы видят только IP-адрес, как любой сайт. Обновление можно выключить: «Настройки → Курсы валют → Обновлять курсы». Тогда приложение не выходит в сеть совсем, а курсы вводятся вручную.

## Клавиатура
В приложении работает только системная клавиатура iOS. Сторонние клавиатуры отключены: у них может быть доступ к сети, и набранное могло бы уйти наружу.

## Face ID и экран блокировки
- Проверку Face ID / Touch ID / код-пароля выполняет iOS. Приложение получает только ответ «да» или «нет» и не видит биометрические данные.
- Замок закрывает всё, включая открытые окна. В переключателе приложений экран скрыт.
- Виджет на экране блокировки — просто кнопка «Новая трата». Он не читает и не показывает траты.

## Перенос на новый iPhone
Файл переноса создаётся только по вашей команде. Он шифруется паролем, который вы придумываете: ключ получается через **PBKDF2-SHA256** (310 000 итераций, случайная соль), затем данные шифруются **AES-256-GCM**. Пароль нигде не сохраняется. Как передать файл (AirDrop, «Файлы»), решаете вы. Без пароля файл не открыть.

Таблица для Excel (CSV) **не зашифрована**.

## Удаление
«Настройки → Удалить все данные» стирает траты и ключ шифрования. Удаление приложения тоже стирает всё.
