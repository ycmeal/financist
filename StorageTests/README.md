# Тесты сохранности данных

Тесты гоняют настоящий код хранения приложения (`AppStore`, `EncryptedStore`, модели) со
управляемыми заглушками: заблокированный iPhone, сбоящая связка ключей, «ключ не найден»,
повреждённый файл, файл из более новой версии, нехватка места и т. д.

Запуск (macOS с Xcode или Linux со Swift 5.9+):

```sh
cd StorageTests
python3 sync.py     # скопировать актуальный код из Financist/
swift test -c release -Xswiftc -enable-testing
```

`sync.py` копирует файлы из `Financist/` и заменяет Apple-only части заглушками из
`Shims.swift` и `TestCrypto.swift`. `TestCrypto` — учебная замена AES-GCM только для тестов
(проверка подлинности есть, стойкости нет); в приложении работает системный CryptoKit.

Запускайте тесты после любых изменений в хранении данных или в модели `Vault`.
